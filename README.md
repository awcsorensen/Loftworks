# Loftworks 0.77.1.3-prerelease

Loftworks is a mod for Kerbal Space Program 1.12 that allows full vertex control part modelling via a custom editor. Shape a Loft by editing a series of cross-sections, with lofts available with 8/16/32/64 vertex options, simple surface parts and panel variants available. 

<img width="1000" alt="screenshot54" src="https://github.com/user-attachments/assets/46e8fb95-1ed9-418b-abe8-03e5ec20247a" />


## Features

- Form Lofts with a wide range of assistant tools such as *Flatten*, *Curve*, *Template Blending*, and many more!
- Use boolean operations to cut through the Lofts and easily create cutouts.
- Customise texture materials, panel borders and weathering in the *Appearance Editor*.
- Set up native Loftworks hinges, slides and control surfaces, and sequence events with the *Loftworks Motion Editor* window.
- Save shapes as templates or save complete Lofts and share them with the *Loftworks Pre-Mades Library*.

## How to use

### To get started, select a Loftworks part from the Structural parts tab in the VAB or SPH, open the KSP PAW and select *Open Loft Editor*.
- Play around with the editor and see what happens!

### To create control surfaces you will need to open the *Motion Editor* button from the *Loft Editor* window or the PAW
1. Activate motion with *Motion Active?* and then select control surface from the 3 options.
2. Set your motion axis origin through specific vertices or through the part origin.
3. Set your motion limits and then you can adjust the settings like a normal control surface
###### *FAR is untested at this point but stock aero works in initial testing.*

## Installation

- Download the Core zip from the releases page and your choice of Texture Pack quality.
- Copy the Core GameData folder to your KSP directory.
- Copy the Texture Pack GameData folder and replace all files.

## Dependencies

**Textures Unlimited** is an optional dependency for Metallic and PBR finishes, without TU then standard shaders are applied.
https://github.com/shadowmage45/TexturesUnlimited

**ModuleManager** is an optional dependency used for bundled compatibility patches for FAR, and to disable Tweakscale on Lofts.
[http://forum.kerbalspaceprogram.com/threads/55219-Module-Manager-1-5-6](https://forum.kerbalspaceprogram.com/topic/50533-18x-112x-module-manager-423-july-03th-2023-fireworks-season/)
